Задание 1. `Files.readString/writeString`
Сохраните каталог курсов в UTF-8, прочитайте, обработайте отсутствие файла и существующий каталог вместо файла. Не ловите ошибку только ради печати и продолжения с ложным успехом.

Задание 2. `Reader`/`Writer`
Перепишите текстовую обработку через buffered reader/writer, считайте строки и символы. Объясните границу bytes → chars.

Задание 3. Try-with-resources
Создайте pipeline чтения и записи, в середине которого возникает исключение. Докажите закрытие обоих ресурсов и правильный порядок close.

Задание 4. Ленивые строки
Используйте `Files.lines` только внутри try-with-resources. Воспроизведите ошибочный возврат stream наружу и объясните, кто обязан владеть ресурсом.

Задание 5. Бинарный формат
Запишите magic header, version, количество и записи через `DataOutputStream`; прочитайте через `DataInputStream`. Отклоняйте неизвестную версию и обрезанный файл.

Задание 6. Временный файл и move
Записывайте новый каталог во временный файл того же каталога, flush/close, затем заменяйте целевой файл move-операцией. Обработайте отсутствие atomic move на файловой системе.

Задание 7. Частично повреждённый импорт
Импортёр собирает ошибки с номерами строк и не публикует половину каталога. Выберите atomic all-or-nothing либо partial result и зафиксируйте контракт типом результата.

Задание 8. Потоковый импорт большого файла
Обработайте файл, превосходящий доступную память, без `readAllLines`. Поддержите счётчики, ограниченный список ошибок и отмену после заданного порога.

Задание 9. Версионируемый формат
Добавьте schema version, checksum и migration из версии 1 в 2. Неизвестная будущая версия не читается как старая. Повреждение обнаруживается до публикации объектов.
