# Task 3 — Потокобезопасный реестр сессий

Файлы: `SessionRegistry.java`, `SessionRegistryDemo.java`, тест
`test/SessionRegistryTest.java`.

`SessionRegistry` хранит сессии в `ConcurrentHashMap`. Операция «создать,
только если отсутствует» реализована атомарно:

- `putIfAbsent(id, session)` — атомарная проверка и вставка на уровне ключа;
  `null` в результате означает, что сессия создана этим вызовом;
- `computeIfAbsent(id, ...)` — атомарно вычисляет и вставляет значение, если
  ключа ещё нет.

Оба метода не требуют внешней блокировки всего реестра и не позволяют двум
потокам одновременно создать две разные сессии с одним `id`. Тест запускает
16 потоков, которые одновременно пытаются создать `s1`, и проверяет, что
победитель ровно один, а размер реестра равен 1.

Запуск:

```bash
mvn -q -Dtest=SessionRegistryTest test
java -cp target/classes task3.SessionRegistryDemo
```
